## 발견 사항

### P2-1 — 헤더 trap-alignment 라벨이 학습자 대상 설명 없이 노출

- 원문 위치: 각 항목 헤더 — 예 "## 전력-3 — 코로나 현상 · 대표 기출
  `2019_3회_38` · adjacent".
- 문제점: `adjacent` / `exact` / `partial+sub`는 분석 문서(v2.1·day plan)의
  trap-alignment 라벨이다. Day 1 로그 "쓰는 법"에는 이 용어 정의가 없어, 학습자가
  "adjacent"가 무엇인지 모른 채 마주친다. 학습 로그 사용 자체를 막지는 않음
  (6칸 내용은 자기충족적) — 순수 학습 로그로는 약한 분석 잔재.
- 제안: "쓰는 법"에 한 줄 추가 — 예: "헤더의 adjacent/exact는 함정 종류 표시 —
  adjacent는 3회독 체크가 함정 2개를 묻는다는 뜻. 모르면 무시하고 6칸만 봐도 됨."
  또는 라벨을 헤더에서 제거. 둘 다 선택적.
- 우선순위: **P2** (선택 — 차단 아님)

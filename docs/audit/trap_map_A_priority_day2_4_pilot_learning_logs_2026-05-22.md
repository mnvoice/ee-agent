## 쓰는 법

각 항목은 6칸이다. 한 번에 다 하지 말고 회독마다 해당 칸만 본다.

- **1회독** — 외울 문장을 소리 내어 외우고, 대표 기출을 푼다.
- **2회독** — 원리 질문에 스스로 답한다. 막히면 "틀리면 → 돌아갈 원리"로.
- **3회독** — 함정 즉답 체크만 빠르게. O/X·단답으로 즉답되면 통과.
- "예상 오답"은 시험장에서 자기가 걸릴 만한 패턴 — 미리 알고 피한다.
- "다음 회독 한 줄"은 다음 번에 이 항목에서 가장 먼저 떠올릴 문장.

항목 제목 옆 표시는 함정 종류다 — 모르면 무시하고 6칸만 봐도 공부에 지장 없다.

- **exact** — 대표 기출이 카드의 함정을 그대로 검증한다. 3회독 체크 1개만 보면 된다.
- **adjacent** — 대표 기출이 카드의 *원래 함정*과는 다른 하위 함정을 검증한다.
  3회독 체크가 함정 2개를 묻는다 — 둘 다 답해야 통과.
- **partial+sub** — 한 항목을 main 문제 + 보조(sub) 문제로 나눠 푼다. main과
  sub가 각각 다른 축을 맡으니, 묶음으로 다 풀어야 항목이 채워진다.

대상: Day 2 변압기·동기기 7항 / Day 3 유도기 4항 / Day 4 직류기 5 + 전기설비 2항.

## Day 2 — 전기기기 변압기·동기기 (7항)

### 기기-1 — 동기발전기 병렬운전 조건 · 대표 기출 `2022_2회_55` · adjacent

- **1회독 — 외울 문장**: 동기발전기 병렬운전 4조건 = 기전력의 크기·위상·주파수·
  파형이 모두 같을 것.
- **2회독 — 원리 질문**: 위상이 어긋나면 왜 동기화전류가 흐르나?
  (→ 위상을 다시 맞추려는 유효분 전류가 생겨 두 기기를 동기 상태로 끌어당긴다)
- **3회독 — 함정 즉답 체크**: 위상차가 생기면 어떤 전류가 흐르나? 기전력 크기차가
  생기면? (위상차 → 동기화전류 유효분 / 크기차 → 무효순환전류 — 분담 아님)
- **틀리면 → 돌아갈 원리**: 위상차 = 동기화전류(유효분), 크기차 = 무효순환전류.

- **예상 오답 패턴**: 위상차 결과를 "무효전력"·"고조파 무효순환전류"로 고름.
  기전력 크기를 다르게 해 분담한다는 보기를 옳다고 봄.
- **다음 회독 한 줄**: 위상차 → 동기화전류, 크기차 → 무효순환전류. 크기 조정은
  분담 수단 아님.

### 기기-2 — 동기기 전기자반작용 · 대표 기출 `2008_1회_51` · exact

- **1회독 — 외울 문장**: 동기기 전기자반작용 — 지상(뒤진) 전류는 감자, 진상(앞선)
  전류는 증자, 동상은 교차(횡축)작용. 동기전동기는 발전기와 반대.
- **2회독 — 원리 질문**: 왜 전류 위상에 따라 반작용 종류가 달라지나?
  (→ 전기자 전류가 만드는 자속이 주자속에 대해 위상마다 다르게 놓여 — 더하거나
  빼거나 비튼다)
- **3회독 — 함정 즉답 체크**: 동기전동기에서 진상 전류의 전기자반작용은? 지상
  전류는? (진상 → 감자 / 지상 → 증자 — 발전기는 반대)
- **틀리면 → 돌아갈 원리**: 전기자반작용은 부하 위상에 따라 달라진다 — "위상과
  무관하게 일정"은 틀림.
- **예상 오답 패턴**: "전기자반작용이 부하 종류와 무관하게 일정"을 옳다고 봄.
  동기발전기/전동기의 증자·감자 방향을 거꾸로.
- **다음 회독 한 줄**: 진상/지상에 따라 증자/감자가 갈린다. 발전기 ↔ 전동기는 반대.

### 기기-3 — 동기속도·권계수·유기기전력 · main `2012_1회_59` + sub `2011_2회_47` + sub `2015_2회_55` · partial+sub

문제 3개를 함께 푼다 — main(동기속도 축) + sub-1(권선계수 계산 축) + sub-2(분포
계수 식 축).

- **1회독 — 외울 문장**: 동기속도 Ns = 120f/P. 유기기전력 E = 4.44fΦN·kp·kd
  (kp = 단절권계수, kd = 분포권계수). 분포권계수 = sin(π/2m)/(q·sin(π/2mq)).
- **2회독 — 원리 질문**: 권계수(kp·kd)를 왜 곱해 주나?
  (→ 실제 권선은 분포·단절권이라 합성 기전력이 줄어든다. 그 감소를 보정하는 계수)
- **3회독 — 함정 즉답 체크** (축별):
  - main `2012_1회_59` (동기속도 축): 동기 조상기의 회전수는 무엇으로 정해지나?
    (Ns = 120f/P)
  - sub-1 `2011_2회_47` (권선계수 계산 축): 권선계수는 무엇과 무엇의 곱? 단절권
    75%면 kp는? (kp·kd / kp = sin(0.75 × 90°))
  - sub-2 `2015_2회_55` (분포계수 식 축): 분포권계수 식은?
    (sin(π/2m)/(q·sin(π/2mq)))
- **틀리면 → 돌아갈 원리**: 동기속도는 주파수·극수만으로, 권계수는 권선 배치 보정
  계수. kp = kd = 1로 가정한 식을 실제 발전기에 그대로 쓰면 틀린다.
- **예상 오답 패턴**: main — 회전수를 효율·역률·토크로. sub-1 — 권선계수를 kp 또는
  kd 하나로만. sub-2 — 분포계수 식의 분자/분모 형태 혼동.
- **다음 회독 한 줄**: Ns = 120f/P / E에는 kp·kd가 곱해진다 / 분포권계수
  sin(π/2m)/(q·sin(π/2mq)).

### 기기-5 — 동기기 단락비 · 대표 기출 `2020_1회_56` · adjacent

- **1회독 — 외울 문장**: 단락비 ks = 무부하 정격전압 여자전류 ÷ 3상 단락 정격전류
  여자전류 = If0/Ifs = 1/%Z(p.u.). 단락비가 크면 동기임피던스 작고·전압변동
  작고·안정도 좋다.
- **2회독 — 원리 질문**: 단락비가 크면 왜 단락전류가 큰가?
  (→ 단락비 = 1/%Z. %Z가 작으면 같은 전압에서 흐르는 단락전류가 커진다)
- **3회독 — 함정 즉답 체크**: 단락비 정의식은? 단락비가 크면 단락전류는 큰가
  작은가? (If0/Ifs / 크다)
- **틀리면 → 돌아갈 원리**: 단락비 큼 = %Z 작음 → 단락전류 큼. "크면 단락전류
  작다"는 정반대.
- **예상 오답 패턴**: "단락비가 크면 단락전류도 작다"를 옳다고 봄. 정의식 If0/Ifs를
  Ifs/If0으로 도치.
- **다음 회독 한 줄**: 단락비 = If0/Ifs = 1/%Z. 크면 단락전류도 크다.

### 기기-6 — 변압기 전압변동률 · 대표 기출 `2021_3회_55` · adjacent

- **1회독 — 외울 문장**: 변압기 전압변동률 ε = p cosθ ± q sinθ (지상 부하 +,
  진상 부하 −). p = %저항강하, q = %리액턴스강하.
- **2회독 — 원리 질문**: 진상 부하에서 ε이 음수가 될 수 있는 이유는?
  (→ 진상에서는 q sinθ 항이 빼지면서 강하가 상쇄돼 2차 전압이 오히려 올라갈 수 있다)
- **3회독 — 함정 즉답 체크**: 진상 부하에서 ε 부호는? ε이 음수가 될 수 있나?
  전압변동률이 무부하 2차전압에 반비례하나? (진상 − / 음수 가능 / 반비례 아님)
- **틀리면 → 돌아갈 원리**: ε는 부하역률·부하전류·%Z에 따라 변하고 진상에서 음수
  가능. "항상 양수", "무부하 2차전압 반비례"는 틀림.
- **예상 오답 패턴**: ε이 항상 양수라고 봄. "전압변동률이 무부하 2차 단자전압에
  반비례한다"를 옳은 설명으로 고름.
- **다음 회독 한 줄**: ε = p cosθ ± q sinθ, 진상이면 음수 가능. 항상 양수 아님.

### 기기-8 — 변압기 효율 · 대표 기출 `2018_1회_51` · exact (계산형)

- **1회독 — 외울 문장**: 변압기 최대효율 조건 = 철손 = 동손. 철손은 부하와 무관
  (전압·자속에 고정), 동손은 (부하율)²에 비례.
- **2회독 — 원리 질문**: 왜 철손 = 동손일 때 효율이 최대인가?
  (→ 고정손[철손]과 가변손[동손]의 합이 최소가 되는 지점이 둘이 같을 때다)
- **3회독 — 함정 즉답 체크**: 최대효율 조건은? 철손과 동손 중 부하에 따라 변하는
  것은? (철손 = 동손 / 동손만 — 동손 ∝ 부하율², 철손은 부하 무관)
- **틀리면 → 돌아갈 원리**: 최대효율은 철손 = 동손인 부분부하에서. 모든 손실이
  부하에 비례하지 않는다 — 철손은 고정.
- **예상 오답 패턴**: "모든 손실이 부하에 비례 증가"한다고 가정. 최대효율을 무조건
  전부하(100%)에서로.
- **다음 회독 한 줄**: 최대효율 = 철손 = 동손. 철손 고정 · 동손 ∝ 부하율².

### 기기-29 — 변압기 내부고장 보호 · 대표 기출 `2021_3회_57` · adjacent

- **1회독 — 외울 문장**: 변압기 내부고장 보호 계전기 = 차동·비율차동·부흐홀츠
  계전기. 부흐홀츠는 절연유 분해 가스를 검출.
- **2회독 — 원리 질문**: 비율차동계전기가 외부 단락에는 동작하지 않는 이유는?
  (→ 1차·2차 전류의 차로 판단. 외부 사고는 들어온 전류 = 나간 전류라 차가 0,
  내부 사고만 차가 생긴다)
- **3회독 — 함정 즉답 체크**: 변압기 내부고장용 계전기 3개는? 비율차동이 외부
  단락에도 동작하나? (차동·비율차동·부흐홀츠 / 안 한다 — 내부만 선별)
- **틀리면 → 돌아갈 원리**: 내부고장용 = 차동·비율차동·부흐홀츠. 비율차동은 전류

- **예상 오답 패턴**: 과전압·과전류 계전기를 변압기 내부고장용으로 고름.
  "차동계전기가 외부 단락에도 동작한다"를 옳다고 봄.
- **다음 회독 한 줄**: 변압기 내부고장 = 차동·비율차동·부흐홀츠. 외부 단락엔
  비율차동 동작 안 함.

  함께 묶어 본다.

## Day 3 — 전기기기 유도기 (4항)

### 기기-10 — 유도전동기 토크-슬립 · 대표 기출 `2021_1회_51` · adjacent

- **1회독 — 외울 문장**: 유도전동기 토크 T ∝ V²(공급전압 제곱). 2차 주파수
  f2 = sf. 슬립 s = (Ns − N)/Ns.
- **2회독 — 원리 질문**: 슬립이 0이면 토크가 왜 0인가?
  (→ s = 0이면 회전자와 회전자계의 상대속도가 0 → 회전자에 유도작용이 안 생겨
  토크가 없다)
- **3회독 — 함정 즉답 체크**: 전압이 2배면 토크는 몇 배? 토크-슬립 식에서 슬립
  s는 분자·분모 어디에? (4배 — T∝V² / 분자 s, 분모 (sX₂)²)
- **틀리면 → 돌아갈 원리**: 토크는 전압 제곱에 비례 — 2배면 4배. 슬립은 손실률이
  아니라 회전자계와 회전자의 상대속도 비.
- **예상 오답 패턴**: "전압 2배면 토크 2배"로 단순 비례 적용. 슬립을 단순 손실률로
  해석.
- **다음 회독 한 줄**: T ∝ V²(2배 → 4배), f2 = sf. 슬립은 상대속도 비.

### 기기-11 — 유도전동기 전력변환 · 대표 기출 `2011_1_60` · exact

- **1회독 — 외울 문장**: 유도전동기 2차입력 P2 : 2차동손 Pc2 : 기계출력 Po
  = 1 : s : (1−s). 즉 Po = (1−s)P2.
- **2회독 — 원리 질문**: 슬립이 작을수록 2차 효율이 좋아지는 이유는?
  (→ 2차 동손 Pc2 = sP2. 슬립이 작으면 동손으로 빠지는 양이 적어 기계출력 비중이
  커진다)
- **3회독 — 함정 즉답 체크**: 2차입력 : 2차동손 : 기계출력 비는? 기계출력과
  2차입력이 같은가? (1 : s : (1−s) / 다르다 — Po = (1−s)P2)
- **틀리면 → 돌아갈 원리**: Po = (1−s)P2 — 기계출력은 2차입력에서 슬립만큼(2차
  동손) 빠진 값. 같지 않다.
- **예상 오답 패턴**: 기계출력과 2차입력을 같다고 봄. 비를 1:(1−s):s 등으로 도치.
- **다음 회독 한 줄**: P2:Pc2:Po = 1:s:(1−s). 기계출력 ≠ 2차입력.

### 기기-12 — 유도전동기 비례추이 · 대표 기출 `2018_1회_44` · exact

- **1회독 — 외울 문장**: 권선형 유도전동기 비례추이 — r2/s = 일정. 2차 저항을
  키우면 최대토크가 생기는 슬립이 커진다(곡선 이동). 최대토크 크기 자체는
  변하지 않는다.
- **2회독 — 원리 질문**: 2차 저항을 키워도 최대토크 크기가 그대로인 이유는?
  (→ 최대토크는 r2/s가 특정 값일 때 발생. r2를 키우면 같은 r2/s를 만드는 s가
  커질 뿐, 최대토크 값은 동일)
- **3회독 — 함정 즉답 체크**: 2차 저항을 키우면 최대토크 *크기*는? 발생 *슬립*은?
  (크기 불변 / 슬립 증가)
- **틀리면 → 돌아갈 원리**: 비례추이는 곡선을 슬립축으로 '이동'시킬 뿐 — 최대토크
  크기는 불변.
- **예상 오답 패턴**: "2차 저항을 심입(증가)하면 최대토크가 변한다/커진다"를 옳다고
  봄 — 이게 대표 기출의 오답 보기.
- **다음 회독 한 줄**: 비례추이 — 최대토크 크기 불변, 발생 슬립만 이동.

### 기기-13 — 유도전동기 E·f·권수비 · main `2015_1회_41` + sub `2008_1회_41` · partial+sub

문제 2개를 함께 푼다 — main(2차 여자 축) + sub(f2 = sf 계산 축).

- **1회독 — 외울 문장**: 유도전동기 1차 유기기전력 E1 = 4.44fΦN1. 회전 시 2차
  유기기전력 E2s = sE2, 2차 주파수 f2 = sf. 정지 시(s = 1)에는 변압기 2차처럼 작동.
- **2회독 — 원리 질문**: 회전자가 빨라지면(슬립이 작아지면) 2차 주파수가 왜 줄어드나?
  (→ 2차 주파수는 회전자계와 회전자의 상대속도가 결정. 회전자가 동기속도에
  가까울수록 상대속도 ↓ → f2 = sf ↓)
- **3회독 — 함정 즉답 체크** (축별):
  - main `2015_1회_41` (2차 여자 축): 2차 여자로 sE2와 같은 주파수의 전압을
    가하면 무엇을 조정할 수 있나? (위상에 따라 속도·역률)
  - sub `2008_1회_41` (f2=sf 계산 축): 회전자(2차) 주파수 f2는? 정지 시 f2는?
    60Hz·슬립 0.1이면 f2는? (sf / f1 / 6Hz)
- **틀리면 → 돌아갈 원리**: f2 = sf — 2차 주파수는 슬립(회전 상태)에 따라 변한다.
  정지 시 f1, 회전 시 감소.
- **예상 오답 패턴**: main — 2차 여자가 출력 자체를 바꾼다고 봄. sub — f2를 회전과
  무관하게 60Hz로, 또는 600Hz 등으로.
- **다음 회독 한 줄**: f2 = sf, 정지 시 f1. 60Hz·슬립 0.1 → 6Hz.

### 기기-14 — 직류전동기 출력·토크 · 대표 기출 `2022_2회_54` · adjacent

- **1회독 — 외울 문장**: 직류전동기 토크 T ∝ Φ·Ia, 출력 P = Tω. 직권전동기는
  Φ ∝ Ia(불포화)라 T ∝ Ia².
- **2회독 — 원리 질문**: 직권전동기 토크가 전류의 제곱에 비례하는 이유는?
  (→ T ∝ Φ·Ia인데 직권은 계자가 전기자와 직렬이라 Φ도 Ia에 비례 → T ∝ Ia²)
- **3회독 — 함정 즉답 체크**: 직권전동기 토크는 전류에 어떻게 비례하나? 토크와
  출력은 같은 변수로 정해지나? (제곱비례 T∝Ia² / 다른 변수 — 토크=Φ·Ia,
  출력=토크·속도)
- **틀리면 → 돌아갈 원리**: 토크 = 자속 × 전기자전류, 출력 = 토크 × 속도 — 서로
  다른 변수 조합. 직권은 자속까지 전류에 묶여 T ∝ Ia².
- **예상 오답 패턴**: 직권전동기 토크를 전류에 '단순 비례'로 봄. 출력과 토크가
  같은 변수로 정해진다고 봄.
- **다음 회독 한 줄**: T ∝ Φ·Ia (직권은 T ∝ Ia²), 출력 = 토크 × 속도.

### 기기-15 — 직류전동기 속도 특성 · 대표 기출 `2012_2회_53` · adjacent

- **1회독 — 외울 문장**: 직류전동기 속도 N ∝ (V − IaRa)/Φ. 직권전동기는 무부하
  시 위험(속도 폭주), 분권전동기는 무여자(계자 단선) 시 위험.
- **2회독 — 원리 질문**: 직권전동기를 무부하로 돌리면 왜 위험한가?
  (→ 부하가 없으면 Ia가 작아지고 직권은 Φ ∝ Ia라 자속도 작아진다 → N ∝ 1/Φ로
  속도가 무한정 올라간다)
- **3회독 — 함정 즉답 체크**: 위험한 운전 상태 — 직권전동기는? 분권전동기는?
  자속이 늘면 속도는? (직권 무부하 / 분권 무여자 / 속도 ↓ — N ∝ 1/Φ)
- **틀리면 → 돌아갈 원리**: 속도는 자속에 반비례(N ∝ 1/Φ). 자속이 늘면 속도는
  내려간다. 직권 무부하·분권 무여자가 폭주 위험.
- **예상 오답 패턴**: "자속이 증가하면 속도도 증가"한다고 봄. 직권 무부하/분권
  무여자를 거꾸로(직권 무여자·분권 무부하).
- **다음 회독 한 줄**: N ∝ (V − IaRa)/Φ — 자속 ↑ → 속도 ↓. 직권 무부하 / 분권
  무여자 위험.

### 기기-16 — 직류기 유기기전력 · 대표 기출 `2018_3회_57` · adjacent

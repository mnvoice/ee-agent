### needs_replacement — 5항

**기기-19 유도전압 조정기 — `2004_2회_56`**
- v3.2 trap: 권수비 변화로만 전압을 조정한다는 보기. (핵심: 단상 90° 위상 조정 /
  3상 회전자계 위상 조정)
- 기출: "단상 유도전압조정기에서 *단락권선의 역할*?" 정답 (4) 전압강하 경감.
- 문제: 단락권선 역할은 유도전압조정기의 주변 디테일 — v3.2 함정의 핵심(전압을
  *어떻게* 조정하는가: 위상 회전 vs 권수비)을 검증하지 않는다. 인접이 아니라 어긋남.
- 관계 **mismatch** / 판정 **needs_replacement**.
- 대체 후보 방향: 단상/3상 유도전압조정기가 전압을 조정하는 *원리*(권선 위치
  회전·회전자계 위상)를 묻는 clean 문항.

**기기-25 동기전동기 V곡선 — `2014_2회_50`**

  출력 일정, 무효분만 변함)

  일정 시 계자전류↔전기자전류)인데, 정답이 (3) "계자전류 일정 시 전기자전류와
  출력 관계"로 표기됨. **정답 표기와 표준 정의가 충돌** — 정답 근거 불충분.
- 관계 평가 불가(정답 신뢰 불가) / 판정 **needs_replacement**.
- 대체 후보 방향: 부족/과여자에 따른 역률 변화, 또는 계자전류 변경 시 출력 불변·
  무효분 변화를 묻는 *정답 검증된* clean 문항 (selection의 alt `2011_3회_58` 등 검토).

**기기-28 단권변압기 — `2013_3회_59`**

- 기출: 문제 text는 "단상 단권변압기 3대 Y결선 ... 자기용량은?"인데 **보기 4개가
  전부 복소수 근(s=±j√20·√30·√40·√50)** — 다른 문제(특성방정식 근)의 보기가 잘못
  들어감. 문제-보기 정합 실패.
- source-clean **FAIL** (구조 검출기는 통과하나 보기가 문제와 무관).
- 관계 평가 불가 / 판정 **needs_replacement**.
- 대체 후보 방향: 자기용량/부하용량 비 (V1-V2)/V1을 직접 묻거나 계산하는 clean
  문항 — 문제-보기 정합 필수 확인 (selection의 alt `2016_2회_52` 등 검토).

**설비-30 가공지선 — `2006_1회_29`**

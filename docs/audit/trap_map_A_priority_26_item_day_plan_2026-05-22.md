## Day 3 — 전기기기 유도기 (4항)

### 오늘의 목표
유도전동기의 모든 양(토크·전력·주파수)이 **슬립 s**에 어떻게 묶이는지 잡는다.
항목 수는 적지만 개념 밀도가 높다 — Day 1·2의 부담을 흡수하는 날.

### 오늘의 핵심 질문
슬립이 변하면 — 토크, 2차 전력 분배, 2차 주파수가 각각 어떻게 변하는가?

### 학습 항목

**[기기-10] 유도전동기 토크-슬립** · 대표 기출 `2021_1회_51` · ★5 S/C
- 외울 것: T ∝ V², f2 = sf, 슬립 s = (Ns−N)/Ns
- 이해할 것: s=0이면 상대속도 0 → 유도작용 사라짐, 부하↑→s↑→토크↑
- ⚠ adjacent: 대표 문제는 *토크-슬립 관계식(s 의존)*을 검증 — 카드 원래 함정(전압
  2배→토크 2배)과 다름
- 풀고 체크: 전압이 2배면 토크는 몇 배? 슬립이 0이면 토크는?
- 오답 → 원리: 전압은 토크에 제곱 비례 / 슬립은 손실률이 아니라 상대속도 비

- ⚠ adjacent: 대표 문제는 *직권 무부하 / 분권 무여자 위험 운전 상태*를 검증 —

2. **adjacent 항목 점검** — adjacent 20항(Section 6 목록)은 대표 문제가 카드의
   원래 함정과 다른 하위 함정을 검증한다. 각 항목에서 *두 함정을 모두* 말할 수
   있는지 확인 — 대표 문제가 검증한 것 + 카드 원래 함정.
3. **주제 중첩 통합** — [기기-29]와 [전력-26]은 같은 보호계전기 주제다. 차동·
   비율차동·부흐홀츠 계전기를 한 표로 묶어 "어떤 계전기가 어떤 사고를 감지하는가"를
   한 번에 정리한다.
4. **partial+sub 항목 마무리** — 기기-3·기기-13·전력-21은 main+sub를 함께 풀어야
   항목 범위가 커진다. sub까지 다 풀었는지 확인.

### 회차별 우선순위 (시간이 부족하면)

- 1순위: exact 6항 (Section 6) — 대표 문제 = 카드 함정. 가장 효율적.

- 3순위: adjacent 17항 — 함정 차이를 의식하며 회독.

## 7. 1·2·3회독 사용법

이 플랜은 한 번 푸는 것으로 끝나지 않는다. 세 번 회독한다.

### 1회독 — 외울 것 확인 → 대표 문제 풀이

- 각 Day의 항목 순서대로 진행.
- 항목마다: "외울 것"을 먼저 소리 내어 확인 → 대표 기출(sub 있으면 main+sub) 풀이
  → "풀고 체크" 질문에 답.
- 틀린 문제 / "풀고 체크"에 막힌 항목은 **표시만 하고 넘어간다** (이번 회차에서
  깊이 파지 않는다).
- 목표: 26항 전체를 한 바퀴 — 어디가 약한지 지도를 그린다.

### 2회독 — 틀린 문제만 원리 질문으로 재풀이

- 1회독에서 표시한 틀린 문제·막힌 항목만 모은다.
- 정답을 외워서 다시 푸는 게 아니라, 카드의 "오답 → 원리"를 *질문 형태*로 바꿔
  자신에게 던지고 → 그 원리로 다시 푼다.
  - 예: 전력-9를 틀렸으면 "비접지 1선 지락 시 회로가 닫히는가?"를 먼저 답하고 풀이.
- 2회독에서도 틀리면 그 항목은 "외울 것"이 아직 안 된 것 — Day 5 복습 루틴 1번으로.

### 3회독 — 보기 함정만 빠르게 판별

- 문제를 처음부터 풀지 않는다. 각 항목 카드의 "대표 보기 함정"(study-set v2.1) +
  "풀고 체크" 질문만 빠르게 훑는다.
- 대표 기출의 오답 보기를 보고 "이게 왜 함정인지" 즉답할 수 있으면 통과.
- adjacent 항목은 *두 함정*(대표 문제가 검증한 것 + 카드 원래 함정)을 모두 즉답.
- 목표: 시험장에서 보기를 보는 즉시 함정을 판별하는 속도.

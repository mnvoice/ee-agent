## 0. 사용 규칙

- trap type: S/C 정상상태↔에너지 변환 / S/F 정적 규칙↔고장·보호 / S/D 정적 공식↔
  시변 신호. (B-pilot에는 S/D 항목 없음 — residual 2.)
- trap alignment: **exact** 3항 / **adjacent** 7항.
  - exact = 대표 기출이 v3.2 카드의 대표 보기 함정을 직접 검증.
  - adjacent = 대표 기출이 같은 주제의 *인접 하위 함정*을 검증 — v3.2 대표 함정과
    검증 포인트가 다르다. adjacent 항목은 "원래 카드 함정"과 "대표 기출이 검증하는
    함정"을 **반드시 분리**해서 학습한다.
- 판정: ready 2 / ready_with_note 8. ready_with_note는 대표 기출이 adjacent이거나
  metadata 오라벨·표기 artifact가 있어 학습 패키지 작성 시 주의 문장이 붙는 항목.

## 0. 6칸 회독 구조

각 항목은 6칸으로 기록한다:

1. **1회독 암기 문장** — 외울 핵심을 한두 문장으로.
2. **2회독 원리 질문** — 왜 그런가를 묻는 질문.
3. **3회독 함정 즉답 체크** — O/X·단답으로 즉답하는 함정 점검. adjacent 항목은
   원래 카드 함정 + 대표 기출 함정을 **둘 다** prompt.
4. **틀리면 돌아갈 원리** — 오답 시 복귀할 근본 원리.
5. **예상 오답 패턴** — 구체적으로 자주 틀리는 형태. adjacent 항목은 각 패턴에
   `[원카드]`(원래 카드 함정)·`[기출]`(대표 기출 함정)·`[core]`(주제 core)
   라벨을 붙여 두 함정의 오답을 분리한다.
6. **다음 회독 한 줄** — 다음 회독에서 보완할 한 줄.

- alignment: exact 3(기기-17, 설비-13, 전력-18) / adjacent 7.
- exact 항목은 카드 함정 = 기출 함정이라 3회독 체크가 단일 함정 — 칸 5 라벨 불요.
- adjacent 항목은 "원래 카드 함정"(v3.2)과 "대표 기출이 검증하는 함정"이 달라,
  3회독 체크에서 둘 다 prompt하고 칸 5 오답 패턴도 라벨 분리한다.

## 전력-3 — 코로나 현상 · 대표 기출 `2019_3회_38` · adjacent

- **1회독 — 외울 문장**: 코로나 임계전압은 도체가 굵을수록, 표면이 매끈할수록,
  상대공기밀도가 높을수록(맑고 기압 높을 때) 올라간다. 코로나의 폐해는 전력손실
  하나가 아니라 잡음·오존·전선부식·통신유도장해까지다.
- **2회독 — 원리 질문**: 상대공기밀도가 낮으면 왜 코로나가 더 잘 생기나?
  (→ 공기가 희박할수록 절연이 약해 더 낮은 전압에서 방전이 시작된다)
- **3회독 — 함정 즉답 체크**: 상대공기밀도가 낮으면 임계전압은 오르나 내리나?
  코로나의 폐해는 전력손실뿐인가? (내린다 → 코로나↑ / 손실뿐 아님)
- **틀리면 → 돌아갈 원리**: 임계전압 ↑ 조건 = 굵은 도체·매끈한 표면·높은
  상대공기밀도. 코로나는 공기 절연이 깨지는 방전 현상 → 손실 외에 잡음·오존도.
- **예상 오답 패턴**: "상대공기밀도가 낮다"를 임계전압이 오르는 경우로 착각(정반대).
  코로나를 "전력손실 문제"로만 좁게 봄.
- **다음 회독 한 줄**: 상대공기밀도 낮음 = 코로나 잘 생김(임계전압↓). 폐해는
  손실+잡음+오존+통신유도.

## 전력-5 — 피뢰기 LA · 대표 기출 `2014_2회_25` · adjacent

- **1회독 — 외울 문장**: 피뢰기는 이상전압이 오면 도통해서 그 전압을 대지로
  방전하고, 곧이어 따라 흐르는 속류만 차단한다. 정격전압은 속류를 끊을 수 있는
  최고 교류 실효값이다.
- **2회독 — 원리 질문**: 피뢰기는 평상시엔 왜 전류가 안 흐르나?
  (→ 비선형 소자라서 평상 전압에선 절연, 이상전압에서만 도통한다)
- **3회독 — 함정 즉답 체크**: 피뢰기 정격전압은 순시값인가 실효값인가? 피뢰기는
  고장전류를 차단하나, 방전하나? (실효값 / 방전 — 고장전류 차단은 차단기)
- **틀리면 → 돌아갈 원리**: 피뢰기 = 이상전압 방전 + 속류 차단. "고장전류 차단"은
  차단기의 일이다. 둘을 섞지 않는다.
- **예상 오답 패턴**: "피뢰기가 고장전류를 차단한다"를 옳은 설명으로 고름.
  정격전압을 순시값(파고값)으로 오인.
- **다음 회독 한 줄**: 피뢰기 = 이상전압 방전·속류 차단, 정격전압은 실효값.
  고장전류 차단 ≠ 피뢰기.

## 전력-7 — 소호리액터 접지방식 · 대표 기출 `2018_2회_25` · adjacent

- **1회독 — 외울 문장**: 소호리액터 접지는 리액터와 선로 대지정전용량이 병렬공진
  해서 1선 지락전류를 거의 0으로 소멸시킨다. 대신 이상전압 위험이 크고 보호계전이
  어렵다.
- **2회독 — 원리 질문**: 왜 지락전류가 0에 가까워지나?
  (→ 용량성 충전전류와 유도성 리액터 전류가 병렬공진으로 서로 상쇄된다)
- **3회독 — 함정 즉답 체크**: 소호리액터 접지는 병렬공진인가 직렬공진인가?
  모든 면에서 우월한가? (병렬공진 / 우월 아님 — 이상전압·보호계전 단점)
- **틀리면 → 돌아갈 원리**: 병렬공진 → 지락전류 상쇄. 장점(지락전류↓·유도장해↓)
  뒤에는 항상 단점(이상전압↑·보호계전 어려움)이 붙는다.
- **예상 오답 패턴**: 공진을 "직렬공진"으로 고름. 소호리액터 접지를 단점 없는
  방식으로 착각.
- **다음 회독 한 줄**: 소호리액터 = 병렬공진으로 지락전류 소멸. 만능 아님
  (이상전압·보호계전 단점).

## 전력-8 — 직접접지방식 · 대표 기출 `2011_1_27` · exact

- **1회독 — 외울 문장**: 직접접지는 지락전류가 크다 → 보호계전이 쉽고, 이상전압이
  작고, 절연레벨을 낮출 수 있다. 대신 통신 유도장해가 크고 차단기 부담이 크다.
- **2회독 — 원리 질문**: 직접접지는 왜 보호계전이 쉬운가?
  (→ 지락 시 전류가 커서 계전기가 사고를 확실하게 감지한다)
- **3회독 — 함정 즉답 체크**: 직접접지의 지락전류는 큰가 작은가?
  (크다 → "지락전류가 작아서 보호계전이 확실"은 거짓 보기)
- **틀리면 → 돌아갈 원리**: 직접접지 = 큰 지락전류. 보호가 쉬운 건 전류가 '커서'지
  '작아서'가 아니다. 큰 전류의 대가가 통신장해·차단기 부담이다.
- **예상 오답 패턴**: "지락전류가 작으므로 보호계전기 동작이 확실하다"를 옳은
  설명으로 고름 — 직접접지를 비접지·소호리액터와 헷갈림.
- **다음 회독 한 줄**: 직접접지 = 지락전류 큼 → 보호 쉽지만 통신장해·차단기 부담.

## 전력-9 — 비접지방식 · 대표 기출 `2015_2회_37` · adjacent

- **1회독 — 외울 문장**: 비접지는 1선 지락 시 회로가 닫히지 않아 지락전류가 작다.
  대신 건전상 전압이 √3배로 오른다(이상전압 큼).
- **2회독 — 원리 질문**: 지락전류가 작은데 왜 완전히 0은 아닌가?
  (→ 선로 대지정전용량을 통해 충전전류가 흐른다)
- **3회독 — 함정 즉답 체크**: 비접지 1선 지락 시 건전상 전압은? 지락전류는 정말
  0인가? (√3배 상승 / 0 아님 — 정전용량 통한 전류 있음)
- **틀리면 → 돌아갈 원리**: 비접지 1선 지락 → 회로 미폐로로 전류는 작지만 0은
  아니고, 건전상 전압은 √3배.
- **예상 오답 패턴**: 건전상 전압이 "변동 없다"고 봄. 지락전류를 "완전 0"으로 봄.
- **다음 회독 한 줄**: 비접지 1선 지락 = 지락전류 작음(0 아님), 건전상 √3배.

## 전력-21 — 중성점 접지방식 비교 · main+sub 3문제 · partial+sub

이 항목은 문제 3개를 함께 푼다 — 한 문제로는 4방식 비교가 안 잡힌다.
main = 전압상승 축 / sub-1 = 다축 비교 / sub-2 = 지락전류 축.

- **1회독 — 외울 문장**: 중성점 접지 4방식(직접·저항·소호리액터·비접지)은 항목별로
  우열이 갈린다. 전압상승이 가장 적은 건 직접접지, 지락전류가 가장 작은 건
  소호리액터접지, 비접지는 보호계전이 불확실하다. 한 방식이 모든 면에서 좋지 않다.
- **2회독 — 원리 질문**: 왜 "모든 면에서 우월한 방식"이 없나?
  (→ 지락전류를 키우면 보호는 쉬워지나 통신장해·차단기 부담이 커지고, 줄이면
  반대 — 축마다 trade-off라서 한 방식이 다 이길 수 없다)
- **3회독 — 함정 즉답 체크** (축별):
  - main `2016_3회_38` (전압상승 축): 건전상 전압상승이 가장 적은 방식은? (직접접지)
  - sub-1 `2009_1회_22` (다축 비교): 비접지는 직접접지보다 유도장해·지락전류가 작다 —
    그럼 보호계전기 동작도 확실한가? (아니다 — 비접지는 보호계전 불확실)
  - sub-2 `2012_1회_39` (지락전류 축): 1선 지락 시 지락전류가 가장 작은 방식은?
    (소호리액터접지)
- **틀리면 → 돌아갈 원리**: 축을 섞지 않는다. 전압상승 = 직접접지가 최소,
  지락전류 = 소호리액터가 최소, 보호계전 = 비접지가 가장 어렵다. 축마다 답이 다르다.
- **예상 오답 패턴**:
  - main: "전압상승 최소"를 소호리액터·비접지로 고름(이상전압이 큰 방식들).
  - sub-1: 비접지의 장점(유도장해·지락전류 작음)에 끌려 "보호계전도 확실"까지
    옳다고 고름.
  - sub-2: "지락전류 최소"를 비접지로 고름(비접지도 작지만 소호리액터가 더 작음).
- **다음 회독 한 줄**: 전압상승 최소 = 직접접지 / 지락전류 최소 = 소호리액터 /
  보호계전 최약 = 비접지. 한 방식이 다 우월하면 함정.

## 전력-24 — 차단기 / 단로기 / 개폐기 · 대표 기출 `2021_2회_26` · exact

- **1회독 — 외울 문장**: 차단기는 부하전류와 고장전류를 끊는다. 단로기는 무부하
  회로를 분리만 한다 — 부하전류·고장전류를 끊지 못한다(아크 소호 능력 없음).
- **2회독 — 원리 질문**: 단로기로 부하전류를 끊으면 무슨 일이 일어나나?
  (→ 아크를 못 꺼서 폭발 위험. 그래서 단로기는 차단기를 연 뒤에만 조작한다)
- **3회독 — 함정 즉답 체크**: 부하전류 차단이 불가능한 개폐장치는?
  (단로기 — 무부하 회로 분리만, 아크 소호 능력 없음)
- **틀리면 → 돌아갈 원리**: 차단 능력 = 아크 소호 능력. 차단기는 있고 단로기는
  없다. 단로기는 "분리"용이지 "차단"용이 아니다.
- **예상 오답 패턴**: 진공·유입·가스 "차단기"를 부하전류 차단 불가로 고름 — 정답
  단로기 대신 차단기 중 하나를 선택.
- **다음 회독 한 줄**: 단로기 = 무부하 분리만, 부하·고장전류 차단 불가.
  차단기 = 부하·고장전류 차단.

## 전력-26 — 발전기·변압기 보호계전기 · 대표 기출 `2011_1_21` · adjacent

- **1회독 — 외울 문장**: 발전기·변압기 내부고장 검출에 가장 많이 쓰는 건
  비율차동계전기. 그 외 차동·부흐홀츠(절연유 분해 가스)·과여자·역률 계전기.
- **2회독 — 원리 질문**: 비율차동계전기는 외부 단락엔 왜 동작하지 않나?
  (→ 1차와 2차 전류의 '차'로 판단한다. 외부 사고는 차가 거의 0, 내부 사고만
  차가 생긴다)
- **3회독 — 함정 즉답 체크**: 내부고장 검출에 가장 많이 쓰는 계전기는?
  비율차동이 외부 단락에도 동작하나? (비율차동 / 안 한다 — 내부만 선별)
- **틀리면 → 돌아갈 원리**: 내부고장용 = 비율차동·차동·부흐홀츠. 비율차동은
  1·2차 전류 차로 동작하므로 외부 사고엔 반응하지 않는다.
- **예상 오답 패턴**: 역상·과전압·과전류 계전기를 내부고장용으로 고름.
  "차동계전기가 외부 단락에도 동작한다"를 옳다고 봄.
- **다음 회독 한 줄**: 내부고장 = 비율차동(1·2차 전류 차). 외부 단락엔 동작 안 함.
- **참고**: Day 2 [기기-29] 변압기 내부고장 보호와 같은 보호계전기 주제 — 함께 묶어 본다.

## 발견 사항

### P1-1 — 3회독 체크 문장 형식 불일치 (14항)

- 원문 위치: 각 항목 "3회독 체크" 줄.
- 문제점: 문서 "사용법" 섹션(10~13행)은 *"3회독 체크 문장에 즉답되면 통과"*라고
  선언 — 질문형(즉답 가능)을 전제한다. 그러나 실제 체크 줄은:
  - **질문형 12항** (즉답 가능): 전력-3,5,7,8,9,21,24,26 / 기기-1,2,3,5
  - **서술형 14항** (사실 진술 — 질문 아님): 기기-6,8,10,11,12,13,14,15,16,27,
    29,30 / 설비-1,19
  Day 1과 기기-1·2·3·5까지는 질문형, 기기-6 이후 14항이 서술형으로 드리프트.
  서술형도 회독 시 사실 확인용으로 쓸 수는 있으나, 문서가 선언한 "즉답" 형식과
  불일치하고 항목 간 일관성이 깨진다.
- 제안: 서술형 14항을 질문형으로 통일. 예시:
  - 기기-6 현재: "ε = p cosθ ± q sinθ — 진상이면 ε 음수 가능. 의존 변수에 무부하
    2차전압 반비례는 없다."
    → 제안: "진상 부하에서 ε 부호는? ε이 음수가 될 수 있나? 전압변동률이 무부하
    2차전압에 반비례하나? (진상 −, 음수 가능, 반비례 아님)"
  - 기기-12 현재: "2차 저항을 키워도 최대토크 크기는 불변, 발생 슬립만 이동."
    → 제안: "2차 저항을 키우면 최대토크 *크기*는? 발생 *슬립*은? (크기 불변,
    슬립 증가)"
  - 기기-16 현재: "E = PZΦN/60a. 중권 a=P / 파권 a=2 — 권선법이 a를 바꾼다."
    → 제안: "중권·파권의 병렬회로 수 a는? 권선법이 E에 영향을 주나? (a=P / a=2,
    영향 줌)"
  (나머지 11항도 동일 패턴 — "...는?" + "(답)" 형식.)
- 우선순위: **P1**

### P1-2 — adjacent 7항의 3회독 체크가 두 함정 중 하나만 prompt

- 원문 위치: adjacent 항목 중 7항의 "3회독 체크" 줄.
- 문제점: 사용법 섹션(16~17행)은 *"adjacent: 3회독 때 두 함정 모두 즉답해야
  통과"*라고 선언. 그러나 다음 7항의 체크 줄은 두 함정(원래 카드 함정 / 대표 기출
  함정) 중 **하나만** 즉답을 유도한다:
  - 전력-3 — 체크는 대표 기출 함정(임계전압 인자)만. 원래 카드 함정(코로나 영향이
    손실뿐) 미prompt.
  - 전력-7 — 체크는 대표 기출 함정(병렬공진)만. 원래 카드 함정(모든 면 우월) 미prompt.
  - 기기-29 — 체크는 대표 기출 함정(계전기 식별)만. 원래 카드 함정(차동계전기 외부
    동작) 미prompt.
  - 기기-10 — 체크는 원래 카드 함정(전압 2배→토크 4배)만. 대표 기출 함정(토크-슬립
    관계식 형태) 미prompt.
  - 기기-16 — 체크는 원래 카드 함정(권선법↔a)만. 대표 기출 함정(분권발전기 E 계산)
    미prompt.
  - 기기-27 — 체크는 원래 카드 함정(분권발전기 전압 변동)만. 대표 기출 함정(종류별
    특성 종합) 미prompt.
  - 설비-1 — 체크는 대표 기출 함정(시험전압 배수)만. 원래 카드 함정(절연저항↔
    절연내력 혼동) 미prompt.
  두 함정 자체는 항목 상단 bullet 2줄에 모두 적혀 있어 학습자가 *읽을* 수는 있다 —
  그러나 즉답을 유도하는 "3회독 체크" 줄이 한 함정만 다뤄, 사용법의 "두 함정 모두
  즉답" 약속을 그 7항에서 지키지 못한다.
- 제안: 해당 7항 체크 줄에 누락된 함정의 즉답 질문 1개 추가. 예시:
  - 전력-3: 기존 + "코로나의 폐해는 전력손실뿐인가? (아니다 — 잡음·오존·통신유도장해)"
  - 전력-7: 기존 + "소호리액터 접지가 모든 면에서 우월한가? (아니다 — 이상전압·
    보호계전 단점)"
  - 기기-29: 기존 + "차동·비율차동이 외부 단락에도 동작하나? (안 한다 — 내부 선별)"
  - 설비-1: 기존 + "절연내력시험과 절연저항시험을 구분하는가? (고전압 파괴시험 vs
    누설전류 측정)"
  (기기-10·16·27도 동일하게 누락 함정 질문 1개 보강.)
- 우선순위: **P1**

### P2-1 — "오귀속" 추상 표현

- 원문 위치: 기기-3 main 함정 역할 줄(102행) — "효율·역률·토크로 오귀속하는 함정".
- 문제점: "오귀속"은 추상적 한자어로 3회독 즉독성이 떨어진다.
- 제안: "효율·역률·토크 때문이라고 잘못 고르는 함정".
- 우선순위: **P2**

### P2-2 — exact 라벨의 계산형 항목 해석 주의

- 원문 위치: 기기-8(122~125행).
- 문제점: 기기-8은 계산형이라 "오답 보기 함정" 구조가 없다. v2 문서가 "계산으로
  반증"으로 정직하게 표기했으나, `exact` 라벨이 보기-함정형 exact(예: 기기-12)와
  동일하게 읽힐 수 있다.
- 제안: 기기-8 줄에 "(계산형 — 보기 함정 대신 계산에 원리 내재)" 한 구절 명시.

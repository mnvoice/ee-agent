### 1.4 목표 4 — 선택 이유 ↔ v3.2 함정 정합 → **부분 불일치 발견 (핵심 finding)**

각 카드의 `대표 보기 함정`(v3.2 전사)과 `대표 기출`이 **실제로 같은 함정을

- **exact** — 대표 기출이 v3.2 대표 보기 함정을 직접 검증 (해당 함정이 보기로

- **adjacent(인접)** — 대표 기출이 같은 주제(동일 함정 유형 S/C·S/F)의 **다른

- **partial(부분범위)** — 대표 기출이 v3.2 항목 범위의 일부만 커버 (medium 항목).

| 정합도 | 항목 수 | 항목 |
|---|--:|---|
| exact | 6 | 기기-2, 8, 11, 12, 전력-8, 24 |
| adjacent | 17 | 기기-1, 5, 6, 10, 14, 15, 16, 27, 29, 30, 설비-1, 19, 전력-3, 5, 7, 9, 26 |
| partial | 3 | 기기-3, 13, 전력-21 |

핵심: study-set v1의 카드는 **v3.2 학습 카드(정확) + 주제 대표 기출(정확)**을
짝지었으나, 17항(adjacent)은 대표 기출이 v3.2가 명시한 그 보기 함정이 아니라
같은 주제의 다른 하위 함정을 검증한다. 예:

- 기기-1: 대표 보기 함정="기전력 크기를 일부러 다르게" / 기출 `2022_2회_55`는

- 기기-5: 대표 보기 함정="단락비 크면 단락전류 작다" / 기출 `2020_1회_56`은

- 설비-19: 대표 보기 함정="과전류차단기로 지락 차단" / 기출 `2009_1회_87`은

이는 **카드의 사실 오류는 아니다** (v3.2 전사도 정확, 기출도 주제 대표로 정확).
그러나 학습자가 카드의 `대표 보기 함정`을 읽고 `대표 기출`을 풀면 다른 하위 함정을
연습하게 된다. 카드에 **함정 정합 주석이 필요**하다.

exact 6항 검증 예:

- 전력-24 `2021_2회_26`: "부하전류 차단 불가능한 장치?"→단로기. v3.2 함정
  ("단로기가 고장전류 차단")의 정반대를 정답으로 요구 — 정확.

### 1.5 목표 5 — 학습 액션 3단계 실행 가능성 → 23항 실행 가능 / 3항 미완

26항 중 23항의 학습 액션 3단계(먼저 외울 것 / 그다음 풀 문제 [실재 key] / 오답
원리)는 즉시 실행 가능 — 외울 것은 구체적 암기 항목, 풀 문제는 실재 key, 오답
원리는 구체적 원리.

3항(기기-3·전력-21, 그리고 기기-13 일부)은 "그다음 풀 문제"가 `[key] (+ 보조 문항
추가 권장)`으로, 보조 문항이 아직 구체적 key가 아님 → 그 단계는 미완. 보조 문항
확정 전까지 학습 액션의 일부가 placeholder.

### 1.6 목표 6 — pedagogy high/medium 과장 검토 → **high 라벨 과장 (정합도와 혼동)**

study-set v1은 pedagogy 적합성을 high 22 / medium 4로 분류했고, 이는 dry-run의
"high = clean + 함정 명확 + 보기 검증 가능" 정의를 그대로 승계했다.

검토 결과 **두 축이 한 라벨에 섞여 있다**:

- 축 (가) **pedagogy apply 적합성** — 기출이 clean·on-topic·오답 보기가 오개념에
  대응하는가. → 22항 대체로 충족. 후속 pedagogy 해설 작성에 적합.
- 축 (나) **v3.2 함정 정합도** — 기출이 v3.2가 명시한 그 보기 함정을 검증하는가.
  → §1.4대로 exact 6 / adjacent 17 / partial 3.

study-set v1의 "high"는 dry-run 정의상 "보기 검증 가능"을 포함하므로, 학습자는
"high = 이 문제로 그 함정을 검증한다"로 읽기 쉽다. 실제로는 adjacent 17항에서
**그 함정은 직접 검증되지 않는다.** → high 라벨은 축 (나) 기준으로 **과장**이다.
축 (가) 기준으로는 과장 아님.

medium 4항: 과장 아님 — 오히려 기기-27은 main 기출이 분권발전기를 오답 보기로
직접 담아 medium보다 적합도가 높은 편(보수적 라벨).

## 4. 권고

1. **study-set v2 작성 시 함정 정합도 필드 신설** — 각 카드에 exact/adjacent/
   partial 명시. pedagogy 적합성을 "apply 적합성"과 "함정 정합도" 2축으로 분리.
2. **needs-card-edit 17항** — 함정 정합 주석 1줄 추가. 기출 교체 불필요. 사실
   오류가 아니므로 학습 세트로 사용 가능하나, 학습자 혼동 방지를 위해 주석 권장.
3. **needs-alt-question 3항** — 기기-3·전력-21은 보조 문항 발굴 필수, 기기-13은
   권장. 보조 문항 검색은 별도 작업(needs-cleanup 트랙과 병행 가능).
4. **study-ready 6항**은 즉시 사용 가능 — 가장 신뢰도 높은 즉시-가용 풀.
5. study-set v1은 폐기 대상이 아님 — 함정 정합 주석 추가(card-edit)와 보조 문항
   확정(alt-question) 후 study-set v2로 승격. 그 전에도 주제 학습용으로는 사용 가능.

우선순위: study-ready 6항 즉시 가용 → needs-card-edit 17항 주석 편집 후 합류 →
needs-alt-question 3항 보조 문항 확정 후 합류.

## 0. 라벨 정의

### 0.1 pedagogy 적합성 — 2축

v1의 단일 high/medium 라벨은 (가)문제 자체의 품질과 (나)v3.2 함정 정합을 혼동했다.
v2는 2축으로 분리한다.

- **data/apply suitability** (high / medium / low) — 대표 기출 자체가 clean·on-topic·
  오답 보기가 오개념 대응이며 후속 pedagogy 해설 작성에 적합한가.
  → study-set-ready 26항은 모두 source-clean·4지선다·주제 정합 (needs-cleanup 항목은
  이미 제외) → **26항 전부 high**. 이 축은 26항 내에서 변별하지 않는다.
- **trap-alignment** (exact / adjacent / partial) — 대표 기출이 카드의 `대표 보기
  함정`(v3.2 명시)을 검증하는가.
  - **exact** — 카드의 대표 보기 함정과 대표 기출 함정이 직접 일치 (그 함정이 보기로
    등장하거나 정반대를 정답으로 요구).
  - **adjacent** — 같은 주제(동일 함정 유형)의 인접 하위 함정을 검증. v3.2가 명시한
    그 함정은 직접 검증 안 됨.
  - **partial** — 항목 범위의 일부만 검증 → 보조 문항 권장.

### 0.2 기타 약어

D-S = 시험이 보는 형태(S 정적). 현상기원: C 변환 / F 고장. 함정 유형: S/C = 정상상태
모델로 풀지만 본질은 에너지 변환 / S/F = 정적 규칙으로 풀지만 본질은 고장·이상 대응.
key = `{year}_{session}_{q_no}`.

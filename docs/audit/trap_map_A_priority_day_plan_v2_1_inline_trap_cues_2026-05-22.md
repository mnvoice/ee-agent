표기: `exact` / `adjacent` / `partial+sub` = trap-alignment (study-set v2.1 기준).

- 원래 카드 함정: *출력과 토크가 동일 변수로 결정* — 토크 = Φ·Ia, 출력 = 토크·속도,
  별개 변수.
- 대표 기출 함정: "직권전동기 토크 vs 전기자전류?" → (3)전류의 제곱에 비례(T∝Ia²).
  단순 비례와 혼동.
- 3회독 체크: 직권전동기 토크는 전류에 어떻게 비례하나? 토크와 출력은 같은 변수로
  정해지나? (제곱비례 T∝Ia² / 다른 변수 — 토크=Φ·Ia, 출력=토크·속도)

### [기기-15] 직류전동기 속도 특성 — `2012_2회_53` · adjacent
- 원래 카드 함정: *자속 증가가 속도를 증가* — N∝1/Φ, 자속 ↑ → 속도 ↓.
- 대표 기출 함정: 직권 (ㄱ) / 분권 (ㄴ) 위험 운전 상태 → 직권 **무부하** 위험 /
  분권 **무여자** 위험. 둘을 도치하는 함정.
- 3회독 체크: 위험한 운전 상태 — 직권전동기는? 분권전동기는? 자속이 늘면 속도는?
  (직권 무부하 / 분권 무여자 / 속도 ↓ — N∝1/Φ)

### [기기-16] 직류기 유기기전력 — `2018_3회_57` · adjacent
- 원래 카드 함정: *권선법 무관하게 동일 E* — 중권 a=P, 파권 a=2, 병렬회로 수가 다름.
- 대표 기출 함정: 분권발전기 유기기전력 계산 (출력 변화 시 E·단자전압 관계).
- 3회독 체크: 중권·파권의 병렬회로 수 a는? 권선법이 E에 영향을 주나? 분권발전기
  유기기전력 E는 어떻게 구하나? (a=P / a=2 / 영향 줌 / E = 단자전압 + 전기자
  전압강하)

### [기기-27] 직류 분권 발전기 — `2010_2회_46` · adjacent
- 원래 카드 함정: *분권발전기 전압이 부하에 무관하게 일정* — 부하 ↑ → 단자전압 ↓
  (자기-부귀환).
- 대표 기출 함정: "직류발전기 종류별 특성 *틀린 것*" → (2)"분권 발전기가 타여자
  발전기와 같이 전압변동률이 작다"(거짓). 분권은 전압변동이 있다.
- 3회독 체크: 분권발전기는 부하가 늘면 단자전압이 어떻게 되나? 직류발전기 종류별
  특성표에서 분권발전기 보기를 골라낼 수 있나? (단자전압 ↓ — 자기-부귀환 /
  타여자·분권·복권 특성 구분)

### [기기-30] 직류기 전기자 반작용 — `2021_1회_56` · adjacent
- 원래 카드 함정: *보극이 토크를 증가시키는 장치* — 보극은 정류를 돕는 장치.
- 대표 기출 함정: "직류발전기 전기자반작용 설명 *틀린 것*" → (3)"주자속이 왜곡되고
  *증가*한다". 전기자반작용은 주자속을 왜곡·**감소**시킨다.
- 3회독 체크: 전기자반작용은 주자속을 늘리나 줄이나? 보극의 역할은? (왜곡·감소 /
  정류 보조 — 토크 증가 아님)

### [설비-1] 절연내력시험전압 — `2015_3회_87` · adjacent
- 원래 카드 함정: *절연저항시험과 절연내력시험을 혼동* — 절연내력 = 고전압 인가
  파괴 시험, 절연저항 = 누설전류 측정.
- 대표 기출 함정: "시험전압 옳은 것" → (4)"170,000V 초과 중성점 직접접지 ×0.72배".
  전압 구간별 배수(1.5 / 1.1 / 0.72) 매핑 혼동.
- 3회독 체크: 절연내력시험과 절연저항시험을 구분하나? 절연내력 시험전압은 7,000V
  이하에서 정격의 몇 배? (고전압 파괴시험 vs 누설전류 측정 / ×1.5 — 수치는 KEC
  개정 영향 가능, 현행 기준 대조)

### [설비-19] 지락차단장치 시설 — `2009_1회_87` · adjacent

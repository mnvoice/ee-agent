## 사용법 — 3회독 전용

3회독 때 이 문서만 빠르게 훑는다. 문제를 처음부터 풀지 않는다 — 각 항목의
**3회독 체크 문장**에 즉답되면 통과.

- **exact** 항목: 대표 기출이 v3.2 카드 함정을 바로 검증 → 한 줄로 함정 표기.
- **adjacent** 항목: 원래 카드 함정과 대표 기출 함정이 다름 → **둘을 분리 표기**.
  3회독 때 *두 함정 모두* 즉답해야 통과.
- **partial+sub** 항목: main과 sub가 각각 다른 함정 축을 맡음 → main/sub 역할 분리 표기.

표기: `exact` / `adjacent` / `partial+sub` = trap-alignment (study-set v2.1 기준).

### [기기-10] 유도전동기 토크-슬립 — `2021_1회_51` · adjacent
- 원래 카드 함정: *전압 2배면 토크도 2배* — T∝V²이므로 4배. 슬립을 단순 손실률로 봄.

- 대표 기출 함정: "직류발전기 종류별 특성 *틀린 것*" → (2)"분권 발전기가 타여자
  발전기와 같이 전압변동률이 작다"(거짓). 분권은 전압변동이 있다.
- 3회독 체크: 분권발전기는 부하 ↑ → 단자전압 ↓ → 계자전류 ↓ → 자속 ↓ (자기-부귀환).
  전압 일정이 아니다.

### [기기-30] 직류기 전기자 반작용 — `2021_1회_56` · adjacent
- 원래 카드 함정: *보극이 토크를 증가시키는 장치* — 보극은 정류를 돕는 장치.
- 대표 기출 함정: "직류발전기 전기자반작용 설명 *틀린 것*" → (3)"주자속이 왜곡되고
  *증가*한다". 전기자반작용은 주자속을 왜곡·**감소**시킨다.
- 3회독 체크: 전기자반작용 → 주자속 왜곡·감소(증가 아님). 보극은 정류 보조(토크 아님).

### [설비-1] 절연내력시험전압 — `2015_3회_87` · adjacent
- 원래 카드 함정: *절연저항시험과 절연내력시험을 혼동* — 절연내력 = 고전압 인가
  파괴 시험, 절연저항 = 누설전류 측정.
- 대표 기출 함정: "시험전압 옳은 것" → (4)"170,000V 초과 중성점 직접접지 ×0.72배".

- 3회독 체크: 절연내력시험 배수 — 7,000V 이하 ×1.5, 고압 직접접지 ×0.72 등.

### [설비-19] 지락차단장치 시설 — `2009_1회_87` · adjacent
